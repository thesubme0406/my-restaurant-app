# 🍽️ Restaurant Queue & Inventory Management System

A full-stack web application designed to streamline restaurant operations by managing customer queueing, online table reservations, and real-time inventory tracking.

## 🚀 Tech Stack

* **Backend:** PHP, Laravel
* **Frontend:** React, Inertia.js, Tailwind CSS
* **Database:** MySQL
* **Tools & IDE:** Visual Studio, Git & GitHub

## ✨ Key Features

* **Queue Management System:** Real-time queue booking, status tracking, and automated customer notifications.
* **Inventory & Stock Management:** Automated stock-level updates based on orders and incoming supply logs.
* **Multi-Role Access Control:** Customized dashboards and permissions for Customers, Staff, and Managers/Admins.
* **Order & Table Tracking:** Interactive overview for staff to manage active tables and pending orders.
